One-picture meme about AI agents shipping games: you ask your agent to build you a game, it does — and now you're an NPC in it. `main.py` draws the meme with Pillow (no network, no external assets) and writes it to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
